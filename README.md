## 🚀 Sobre o projeto

O objetivo deste projeto é criar uma presença profissional na web, reunindo em um único lugar:

- 👨‍💻 Sobre mim
- 🛠️ Tecnologias e ferramentas
- 📂 Projetos desenvolvidos
- 🐙 Projetos disponíveis no GitHub
- 📚 Estudos e conhecimentos
- 🔐 Interesse em Segurança da Informação
- 📬 Formas de contato

O site foi desenvolvido com foco em **performance, responsividade, acessibilidade e SEO**.

## 🛠️ Tecnologias

O projeto utiliza tecnologias nativas da Web:

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

Não são utilizados frameworks front-end neste projeto, permitindo uma estrutura simples, leve e adequada para hospedagem no **GitHub Pages**.
