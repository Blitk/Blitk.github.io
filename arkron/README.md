# Arkron — versão web

Versão responsiva em HTML, CSS e JavaScript, criada a partir dos arquivos Python enviados.

## Executar
Abra `index.html` no navegador. Não precisa instalar dependências nem usar servidor.

## Arquivos
- `index.html`: estrutura, criação de personagem e interface.
- `style.css`: tema responsivo para desktop e celular.
- `game.js`: atributos, combate, salvamento local e navegação.
- `story.js`: textos extraídos dos capítulos do arquivo `Arkron.py`.

## Observações
- Os textos narrativos foram transferidos dos arquivos originais, mantendo o conteúdo e a ordem dos trechos encontrados.
- O jogo salva o progresso no `localStorage` do navegador.
- A lógica de combate foi adaptada para controles visuais e turnos no navegador; por isso, os números e o equilíbrio das batalhas podem diferir do programa Python.
